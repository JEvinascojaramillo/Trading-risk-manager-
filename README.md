# 📊 Trading Risk Manager (JavaScript)

A professional tool built to automate **Risk Management** calculations. This project focuses on applying core programming logic to solve real-world financial problems.

## 🚀 Key Features
- **Dynamic Lot Sizing:** Calculates the exact position size based on account balance and Stop Loss.
- **Risk Guard:** Built-in validation logic to prevent over-leveraging (max 3% risk).
- **Clean Syntax:** Uses modern JavaScript functions and template literals.

## 🛠️ Skills Demonstrated
- **Mathematical Logic:** Applying financial formulas in code.
- **Data Types:** Working with Numbers, Strings, and Objects.
- **Control Structures:** Implementing `if/else` statements for decision-making.
